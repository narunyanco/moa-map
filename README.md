# 作用機序マップ

疾患別の病態と薬の作用機序、モダリティ（低分子・抗体・核酸・ウイルスなど）別の構造と仕組みを、図で見られる学習用の参考資料です。説明は中学・高校・大学・専門の4段階で切り替えられます。

## 収録内容

- 疾患別：糖尿病、がん、関節リウマチ、脂質異常症、アルツハイマー病、脊髄性筋萎縮症、血友病、喘息・アトピー、ウイルス感染症
- モダリティ別：低分子、ペプチド、タンパク質、抗体（Fc改変・ADC・二重特異性抗体・抗体断片）、核酸（ASO・siRNA・mRNA・アプタマー）、ウイルス医薬品、細胞医薬、ゲノム編集、放射性医薬品、ワクチン、マイクロバイオーム

## 情報の確かさについて

- 各項目に照合状態（添付文書と照合／総説で照合／未照合）を表示しています。未照合の項目は一般的な薬理学の知識に基づく記述です。
- 患者数・死亡数は、人口動態統計・患者調査・WHOなどの公表値を年と出典つきで載せています。二次資料からの値は「二次」と表示しています。
- 薬剤ごとのリンクは、DailyMed・PubChem・PubMed の検索URLを一般名から生成しています。
